## Olá, eu sou Kauã Restoff 👋

### Desenvolvedor de Software com foco em Desenvolvimento Web

Sou desenvolvedor de software focado na criação de aplicações web, sistemas e soluções capazes de transformar ideias e problemas reais em produtos funcionais.

Minha experiência é construída principalmente através da prática, desenvolvendo projetos acadêmicos e pessoais nos quais aplico conceitos de desenvolvimento front-end, back-end, banco de dados, integração de sistemas e organização de software.

Busco compreender não apenas **como escrever código**, mas também como estruturar soluções melhores, organizar projetos, tomar decisões técnicas e desenvolver aplicações que façam sentido para quem realmente vai utilizá-las.

Atualmente, continuo expandindo meu portfólio e aprofundando conhecimentos em **Engenharia de Software, Arquitetura de Sistemas, Inteligência Artificial e Automação**, enquanto busco oportunidades para iniciar e construir uma carreira sólida na área de tecnologia.
